# Grok Bot Bilbao Meetup: brand assets

Goal: own the source that generates the event's marketing material, so changing a logo or a line of text doesn't wait on the designer.

`reference/` holds the designer's delivered files, taken from the Frame.io share "Grok Bot Bilbao Meetup" (Pablo Gonzalez) on 28 Sep 2026. They are the target for any rebuild. The download was not complete when this was committed.

## What the package contains

| Part | Files | Made with (from file evidence) |
| --- | --- | --- |
| Social posts | agenda horizontal 1920×1080, story 1080×1920, @2x, partner variants, 4:5 feed | PNGs with all metadata stripped; likely rendered by code or exported |
| Live screens | 22 screens (pre-show, welcome, agenda, speaker and Q&A per speaker, networking, thanks, BRB), each in clean and `-logo` versions | same as above |
| Screen video | every screen as `_1-in`, `_2-loop`, `_3-out`, `_full` MP4 (1920×1080, 30 fps) | H.264, encoder tags stripped |
| Stream overlays | lower thirds and 5 stingers with alpha, ProRes 4444 `.mov` and VP9 `.webm`, logo bug | ProRes 4444 / VP9 |
| Print | 50×70 cm poster, with and without crop marks | Adobe Illustrator 30.8 |
| Speaker deck | `DESIGN.md` (full design system), 4 PPTX templates with embedded font | generated by code: the PPTX internals match PptxGenJS (Node) |

The live screens README mentions per-speaker "AI Kits (for Claude)" zips containing `build.py`, `talk.json` and `SKILL.md`. Those have not been downloaded yet. They are the deck generator's source.

## Why this is rebuildable

The design system is strict and fully specified in `reference/speaker-deck/DESIGN.md`: black canvas, one font (Universal Sans Display 400), white / #777 / red #EE3342 for times only, 90 px vertical and 80 px side margins, a coloured blob "bot" per speaker. Frame-perfect in/loop/out clips and balanced line breaks point to a programmatic pipeline, not hand animation.

## Open points

- The font is licensed for the event decks only; the DESIGN.md says not to extract or share it. We need our own licence to render with it.
- The bot shapes and their animation curves exist only as rendered output. Recover them as SVG from the stills and PPTX media, or ask for the vectors.
- The simplest path is still to ask the designer for the source project (HTML/Node renderer, Illustrator file, bot SVGs).

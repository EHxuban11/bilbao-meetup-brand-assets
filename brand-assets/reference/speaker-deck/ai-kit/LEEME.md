# Tus diapositivas para el Grok Bot Bilbao Meetup

Este kit prepara tu presentación con el diseño del evento: la tipografía del evento ya va dentro del archivo, tu bot ya está colocado y todo queda alineado a la rejilla. Tú aportas el contenido; tu IA lo maqueta.

## Con Claude (recomendado)

1. Abre Claude (claude.ai o la app) y **adjunta este .zip** a un chat nuevo.
2. Escríbele algo así:

   > Usa el kit adjunto (lee SKILL.md) para hacer las diapositivas de mi charla. Este es mi guion: …

3. Adjunta también las **fotos o capturas** que quieras enseñar.
4. Claude te devolverá un **.pptx**. Ábrelo en **PowerPoint**: la tipografía viaja dentro del archivo.

Si usas Claude a menudo, puedes instalar el kit como skill en **Ajustes → Capacidades → Skills** subiendo este mismo .zip.

## Con otra IA

Dale estos archivos y pídele que siga `SKILL.md`. Necesita poder ejecutar Python para usar `build.py`.

## A mano

Abre `template.pptx` en PowerPoint. Tiene una diapositiva de ejemplo por cada diseño; duplica la que necesites, cambia el texto y borra el resto. Las reglas están en `DESIGN.md` y en las notas de cada diapositiva.

## Antes del evento

Envía a la organización el .pptx y un PDF exportado desde PowerPoint.

Keynote y Google Slides no leen la tipografía incrustada y la sustituyen por otra. Si presentas con ellos, usa el PDF.

La tipografía Universal Sans va incrustada solo para esta presentación: no la extraigas ni la instales.
